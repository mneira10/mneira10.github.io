# Check: AI features

Spawned when the PR changes AI, prompt, retrieval, agent, or model code (plan review, specs code review, copilot).

Follow [../plan-review.md](../plan-review.md). Use only the rows that match the change, and don't turn every AI PR into an architecture audit.
